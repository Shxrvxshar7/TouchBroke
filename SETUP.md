# TouchBroke — Setup

**Step 1:** Install Python from [python.org/downloads](https://python.org/downloads)
— tick **"Add Python to PATH"** during install

**Step 2:** Double-click **StartTouchBroke.bat**
— click Yes on the admin prompt — it installs everything automatically

**Step 3:** First time only — a browser tab opens, log into Spotify and click **Allow**

**Step 4:** Open Chrome on your phone and type the URL shown in the window
— looks like `http://192.168.x.x:8080`

**Step 5:** Rotate your phone sideways
